## 能做什么

把产品与客户任务、内容体系、真实表达、信任、承接和交付反馈连成一套可执行的方法，帮助创作者探索和验证变现路径，不承诺收益。

四个入口：

1. 尚无方向：从经历、能力、资源探索可提供价值，再验证客户问题和付费假设。
2. 已有业务：从产品与客户情境构建选题体系、信任与承接路径。
3. 已有账号：根据实际材料诊断六环，区分证据与假设，给最小验证动作。
4. 明确任务：直接选题、写稿、改稿或复盘，不强制先做账号诊断。

## 如何使用

### 支持 Skill 的宿主

将本目录作为名为 `creator-harness` 的技能目录，手动放入该宿主官方文档指定的技能位置；核心文件是 `SKILL.md`。各产品的目录、导入方式和启用方式不同，请查所用宿主说明，不存在本包统一适用的安装路径。

确认该宿主已加载技能后，以它支持的方式调用；若支持按名称调用，可点名 `creator-harness`。仅下载文件不等于完成安装。

### 不会安装：用单文件

任选 [创作者Harness_单文件使用版.md](./创作者Harness_单文件使用版.md) 或 [创作者Harness_单文件使用版.txt](./创作者Harness_单文件使用版.txt)。二者正文完全相同，包含全部规则、流程、格式与示例。在本仓库中点击上述相对链接即可打开；需要单独保存时，使用该文件页的 Raw 或 Download，或克隆仓库后取根目录中的同名文件。把一个文件上传给支持文件阅读的 AI，再发：

> 请阅读这份文件，按其中的方法帮助我。我现在的情况是：……

也可在支持足够文本长度的对话中粘贴全文。文件只指导当前会话，不自动永久生效；新会话可能需要重新上传。不保证所有 AI 都能读附件或完整保留长文本，也不覆盖其自身规则。

## 调用示例

- 「我没有方向，帮我从已有经历找到一个值得验证的价值假设，一次问一个关键问题。」
- 「我已有产品，材料如下，请从客户任务拆选题体系，不要强迫每条引流。」
- 「下面是脱敏的作品和咨询反馈，诊断证据支持的瓶颈，不要只按播放量下结论。」
- 「按我给的事实写口播，锁定句不许改；任务明确就直接写。」
